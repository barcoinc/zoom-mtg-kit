# Zoom MTG Kit

**打ち合わせを、勝手に議事録になる仕組みに変えるキット。**

案件ごとにZoomの常設リンクを1本作っておくだけで、
そのあとは「録画 → 文字起こし → 議事録 → 案件フォルダに格納」までClaude Codeが通しでやります。

---

## 何ができるか

```
案件ごとに常設リンクを1本作る（1回だけ）
        ↓
  打ち合わせをする（リンクは毎回同じ）
        ↓
  クラウド録画・文字起こしは自動
        ↓
「〇〇の録画を議事録にして」と言うだけ
        ↓
  文字起こしと議事録が案件フォルダに入る
```

議事録は毎回同じ型で出ます。**テーマ / 決定事項 / ToDo（担当・期限） / 議論要点 / 次アクション**、
そして末尾に**そのまま先方に送れるサマリ**が付きます。

## できること（10のツール）

| ツール | 何をするか |
|---|---|
| **`doctor`** | **セットアップの自己診断。うまく動かない時は最初にこれ** |
| `create-meeting` | 案件用の常設Zoomリンクを作る（クラウド録画ONで作られる） |
| `list-meetings` | 予定されているミーティングの一覧 |
| `get-meeting` | 参加URL・パスコード・録画設定を確認する |
| `update-meeting` | 自動録画のON/OFF、名称変更 |
| `list-recordings` | クラウド録画の一覧（何ヶ月遡るか指定可） |
| `download-recordings` | 録画を取得。`transcriptOnly` で文字起こしだけ高速に |
| **`get-share-link`** | **録画をURLで共有する。そのまま貼れる文面まで作る** |
| **`set-share-settings`** | **パスコード無しで誰でも見られる状態にする等** |
| `delete-recording` | 議事録化が済んだ録画をゴミ箱へ（30日以内は復元可） |

すべて日本語で話しかけるだけで動きます。コマンドを覚える必要はありません。

## 4つの使い方

**① 案件ごとの常設リンク** — クライアントごとに1本発行して使い回す。毎回URLを作って送る手間が消えます。

**② 録音機として使う** — 対面の打ち合わせでスマホからこのリンクに入るだけ。カフェでの商談もそのまま文字起こしになります。先方主催のZoomに出る時も、自分側の部屋を別途開いておけば手元に記録が残ります。

**③ 議事録の自動生成** — 溜まった録画をまとめて議事録化。案件フォルダに入るので、次の制作物を作る時の素材になります。

**④ 録画をURLで共有する（Loomのように）** — 「さっきの録画の共有リンク出して」と言うだけで、視聴用URLとパスコード、そのまま貼れる文面が返ります。

```
みどり商事 打ち合わせ（2026/7/29 14:04・74分）の録画です。
https://us06web.zoom.us/rec/share/SxpGhXP5my_...
パスコード: DM8MQJi2Z89a...
```

**パスコード無しで配りたい場合**は「パスコード無しで誰でも見られるようにして」と言えば `set-share-settings` が設定を変えます。
欠席者へのフォロー、社内共有、商談の録画を上長に見せる、といった用途にそのまま使えます。

> **Loomとの違い**：切り出し（トリミング）やハイライト編集はできません。**会議まるごとの共有**になります。
> ブラウザから2クリックで画面録画を始める、という使い方もできません。
> ただし録音用の部屋を1つ作っておけば、**そこに入って画面共有しながら喋って終了する**だけで、
> 実質Loomと同じ「録って共有」の流れになります。

## 入っているもの

```
zoom-mtg-kit/
├─ 導入マニュアル.md      セットアップ手順（まずこれ）
├─ CLAUDE.md             Claude Codeへの指示書（自動で読まれる）
├─ server/               MCPサーバー本体（ビルド済み・そのまま動きます）
└─ workflow/
   ├─ 運用ルール.md        フォルダ構成・命名・議事録化の手順
   ├─ 議事録テンプレート.md  議事録の型
   └─ vtt2md.py           文字起こし(VTT)を読める形に整形するスクリプト
```

## 必要なもの

- **Zoomの有料プラン（Pro以上）** — クラウド録画は無料プランでは使えません
- Zoomアカウントの管理者権限（アプリを作るため）
- Claude Code / Node.js 18以上（**ビルド済みなので `npm install` は不要です**）

## 始め方

**[導入マニュアル.md](導入マニュアル.md) を上から順に。** 20分で終わります。

とくに **手順1（Zoomの「音声文字起こしを作成」をON）は飛ばさないでください。** ここがOFFだと文字起こしが作られず、議事録が作れません。

---

## 大事な注意

**認証情報（Account ID / Client ID / Client Secret）は絶対に他人に渡さないでください。**
渡すと、その相手があなたのZoom録画すべてにアクセスできます。このキットを誰かに渡す時も、`.env.local` は必ず除いてください（`.gitignore` で除外済みです）。

**録音していることは相手に伝えてください。** とくに対面での録音は、ひと言断ってから始めるのが安全です。

**議事録には機微な情報が入ります。** `workflow/運用ルール.md` の通り、議事録フォルダはGitに上げない設定にしてあります。この設計はそのまま引き継いでください。
